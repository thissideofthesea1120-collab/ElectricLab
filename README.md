# 电学虚拟实验室 · ElectricLab

面向中学物理电学与电磁学的 Android 虚拟实验室。横屏沉浸式黑板界面，Material 3 深色设计，全部仪器用 Canvas 矢量绘制，支持实物接线、电表读数、故障损坏和任务闯关。

- 应用名：**电学虚拟实验室**
- 包名：`com.physlab.electric`
- 版本：**2.3.1**（versionCode 43）
- 支持：Android 6.0（API 23）及以上
- 屏幕：强制横屏，横屏方向跟随手机自动翻转，自适应常见手机与平板分辨率
- 完全离线，不申请网络权限

## 当前功能

### 自由实验

- 仪器库：电源、电池组、蓄电池、开关、单刀双掷开关、小灯泡、热敏小灯泡、定值电阻、滑动变阻器、电阻箱、电阻丝、电流表、电压表、灵敏电流计、毫安表、电容、电感、电动机、蜂鸣器、LED、电磁铁、螺线管、条形磁铁、蹄形磁铁、指南针。
- 实物接线：点击接线柱选择导线颜色并连线，支持折线走线、拖动改接、撤销/重做、删除。
- 导线交叉实时提醒；选中仪器和导线有脉冲高亮。
- 电流表/电压表可放大读数，支持量程切换、正负接线柱判断、反接提示和过载损坏。
- 电路仿真：串联、并联、滑动变阻器、电阻箱、电阻丝、电动机、蜂鸣器、LED、电磁铁等。
- 小灯泡亮度按实际功率判断；热敏小灯泡电阻随温度变化。
- 磁场视图：条形磁铁、蹄形磁铁、通电螺线管、电磁铁、指南针；磁感线加粗加密，绕线方向有箭头。

### 实验模板

- 串联电路、并联电路、伏安法测电阻、欧姆定律、电功率、电磁铁、螺线管、磁体、电容充放电等模板。
- 电容充放电模板按实验快照预置仪器和接线；并联模板电流方向按实际电流方向显示。
- 保存实验快照时可以自定义名称，默认按日期时间命名。

### 任务闯关

- 从空实验台开始，自己拖动仪器、接线、填表、提交验证。
- 通过一关解锁下一关；80 分过关，100 分可解锁下下关。
- 每关最高分持久化保存，覆盖更新不丢失进度。
- 右侧常驻数据表；物理规律关需要选择正确结论。
- 拖动滑动变阻器时自动显示小型透明电压表放大刻度，停止拖动后消失。
- 全部通关后显示鼓励语。

关卡包括：

1. 串联电路
2. 并联电路
3. 串联电路电流的规律
4. 并联电路电流的规律
5. 串联电路电压的规律
6. 并联电路电压的规律
7. 电阻大小与什么因素有关
8. 练习使用滑动变阻器
9. 电流与电压的关系
10. 电流与电阻的关系
11. 伏安法测电阻
12. 伏安法测小灯泡电阻
13. 测量小灯泡电功率
14. 观察电容器的充、放电现象
15. 测量电源的电动势和内阻

### 伏安法测电阻

- 实验台预置一个 5/10/15/20 Ω 随机未知定值电阻。
- 不显示阻值，长按也不能查看或更改规格。
- 用户填写的 U、I、R 必须同时满足 R≈U/I 和系统实际阻值才能通过。

### 伏安法测小灯泡电阻

- 预置随机规格热敏小灯泡，显示额定电压。
- 三组数据：较低电压、额定电压、额定电压的 1.2 倍。
- 校验三组 R≈U/I、额定电压、1.2 倍电压以及高温电阻增大。

### 测量小灯泡电功率

- 三行：低于额定电压、额定电压、1.2 倍额定电压。
- 填 U、I、P，并通过下拉选项选择“亮度低 / 正常发光 / 亮度高”。
